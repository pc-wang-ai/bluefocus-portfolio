# 蓝色光标 AI Builder 项目作品集

**姓名：王鹏程**  
应聘岗位：蓝色光标 2027 校招 AI Builder

[作品网站](https://pc-wang-ai.github.io/bluefocus-portfolio/) · [正式提交 PDF](AI_Builder_Portfolio_Final.pdf)

神农中药科研平台用于查询方剂、核对资料来源、比较研究结果，并保存和导出研究记录。我参与需求拆分、功能设计、数据核对，借助 AI 编程工具推进局部实现和测试。这里不以仓库文件数量计算个人独立编码贡献。

## 技术栈

原平台主要使用 Python、Streamlit、pandas、Plotly、NetworkX/PyVis；研究记录使用 SQLite，部分原始数据连接使用 PyMySQL。产品模型功能使用 DeepSeek 兼容接口。数据测试使用 pytest，浏览器操作检查使用 Playwright。

本仓库仅是静态求职展示站，使用 HTML、CSS、图片和 PDF，不连接原平台后台、数据库或模型接口。

## 系统架构

资料来源 → 实体和关系整理 → 查询与证据查看 → 专题比较与 AI 问答 → 研究记录和报告导出。

平台为对象保留来源、版本和缺失状态；模型可通过只读工具补查资料。研究记录保存在 SQLite。网页展示的是原平台截图和历史运行摘要。

## 三项代表功能

1. **方剂检索**：支持名称、别名和药味。示例输入阳旦汤可匹配桂枝汤 F0194。
2. **证据下钻**：从条目、基因、靶点查看化合物实验记录，保留 ChEMBL 编号、活性单位与年份。
3. **研究整理**：比较方剂、保存版本、编排报告并导出。专题中单列缺失层和非蛋白目标记录。

## 验证路径

打开作品网站 → 查看三步截图 → 点击原图核对字段 → 查看 AI 历史案例 → 打开 8 页 PDF。

AI 成功案例来自 AIR-9578e3b22283，同一运行包含有效工具查询、回答和引用，引用/数值检查通过；轨迹也有失败调用。预算不足案例来自另一条 AIR-7d96fc611cdc，二者分别说明。

统计口径沿用 P34：457 首方剂可检索，446 首进入反向索引，581 passed / 1 skipped；指定三方剂案例排除 1,791 条非蛋白活性记录。这些是对应版本的存档结果，不表示本静态站重新执行了科研计算。

手机端可使用顶部导航，截图支持横向阅读和点击原图。PDF 可在线查看或下载。
