# 蓝色光标 AI Builder 项目作品集

[查看作品网站](https://pc-wang-ai.github.io/bluefocus-portfolio/) · [作品集 PDF](AI_Builder_Portfolio_v3.pdf)

主项目为神农中药科研平台，介绍方剂检索、实验记录查看、多方剂比较、研究记录与报告导出，以及产品内 AI 的历史调用案例。

我参与需求拆分、功能设计、数据核对，并借助 AI 编程工具推进局部实现和测试。代码由人工与 AI 协作完成，详细经历见作品集。

辅助项目 XunZi-PD 展示研究结果的双语页面和分层阅读方式。

## 本仓库范围

仅包含静态展示网页、截图和 V3 PDF，不包含神农平台完整源码、数据库、密钥或内部运行和测试文件。

展示网站无需后端，可通过 GitHub Pages 访问。本仓库未授予原科研数据或第三方资料的额外使用许可。

## 本地查看

双击 index.html，或在本目录运行 python -m http.server 8080 后打开 http://127.0.0.1:8080/。
